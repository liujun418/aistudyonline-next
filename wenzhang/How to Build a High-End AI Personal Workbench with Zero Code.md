# How to Build a High\-End AI Personal Workbench with Zero Code

If you want to build a high\-end AI personal workbench without writing a single line of code or having any design experience, WorkBuddy is the perfect tool for you\. This guide will walk you through the entire process, from opening the app for the first time to creating a fully functional, visually appealing workbench\.

## What is WorkBuddy?

WorkBuddy is an AI tool that allows you to create custom workbenches using natural language\. It uses two core Skills to help you build your workbench:

- **Workbench Skill**: This Skill helps you organize your workbench requirements\.

- **UI Skill**: This Skill takes the organized requirements and generates a high\-quality, visually appealing interface\.

## Step 1: Get Started with WorkBuddy

1. Open WorkBuddy for the first time\.

2. The interface is simple:

    - Left sidebar: Your project list\.

    - Right area: AI conversation area where all operations take place\.

## Step 2: Create a New Workspace

1. Click the "New Workspace" button\.

2. Name your workspace \(e\.g\., "My AI Workbench"\)\.

3. Confirm the creation\.

## Step 3: Use the Skills

1. In the input box, type a forward slash \(`/`\)\. This will bring up the two Skills\.

2. The first Skill \(`/finesse-brief`\) is for organizing your workbench requirements\.

3. The second Skill \(`/finesse-ui`\) is for making the page look high\-end and high\-quality\.

## Step 4: Organize Your Requirements

1. Don't rush to generate the page\. First, use the Workbench Skill to organize your requirements\.

2. For example, if you want to create a pet daily record workbench, type:

    ```Plain Text
    /finesse-brief Help me create a pet daily record workbench.
    ```

3. The AI will then ask you a series of questions to clarify your requirements, such as:

    - What do you want to record every day?

    - What should be displayed on the homepage?

    - What should be shown when there is no data on the first day?

    - What content will be used every day in the future?

## Step 5: Generate the Interface

1. Once your requirements are organized, use the UI Skill to generate the interface\.

2. Type:

    ```Plain Text
    /finesse-ui
    ```

3. The AI will generate a complete page design based on your requirements\. Every requirement you specified will be reflected in the interface\.

## Step 6: Compare the Results

1. The default AI\-generated workbench will have a basic design:

    - Gray cards, blue buttons, and centered titles\.

    - It has all the necessary features, but it's not visually appealing\.

2. The workbench generated using the two Skills will be:

    - High\-end and high\-quality\.

    - Easy to use, with the most important information and buttons prominently displayed\.

    - Data\-driven, with different sizes of numbers to show priorities\.

## Step 7: Make Changes

1. After the page is generated, making changes is easy\.

2. For example, if you want to add a vaccine record, type:

    ```Plain Text
    Add a vaccine record.
    ```

3. The AI will add the vaccine record to the existing page without starting over\. This is because the requirements are already in the document, so the AI knows where to add the new content\.

## Step 8: Use the Same Process for Different Topics

1. The same process can be used to create workbenches for different topics\.

2. For example:

    - To create an AI workbench, first organize the requirements \(where to put the chat, workflow, and knowledge base\), then use the UI Skill to generate the interface\.

    - To create a life management workbench, first organize the requirements \(how to display today's plan, how to organize life records, how to view data\), then use the UI Skill to generate the interface\.

## Conclusion

Building a high\-end AI personal workbench is easy with WorkBuddy\. You don't need to write any code or have any design experience\. Just follow these three steps:

1. Say a sentence to describe what you want to record\.

2. Organize your requirements\.

3. Use the UI Skill to generate the interface\.

WorkBuddy is the executor, the Workbench Skill determines what it does, and the UI Skill determines how good it looks\. With WorkBuddy, you can create a custom workbench that meets your specific needs in just a few minutes\.
