# Codex Website Development: Zero\-Basis Practical Tutorial and Deployment Guide

In this tutorial, I’ll show you how to use **Codex** to build a stunning cat\-themed website from scratch, even if you have no coding or design experience\. We’ll cover two building methods and how to deploy your site online\. Let’s get started\!

## Why Codex?

Gone are the days when building a website required mastering programming, code, and UI design—filled with confusing technical jargon\. With Codex, you can overcome technical limitations\. Just tell it your needs like a boss, and it will build the website step by step for you\.

## Method 1: Pure Personalized Building

This method is ideal if you want a detailed, unique\-style website\.

### Step 1: Define the Website Framework

Start by outlining your website’s structure, sections, and overall style\. Input your requirements directly into Codex\. For example:

> "I want to build a cat website\. It should include sections like a cat’s profile, daily diary, photo gallery, growth timeline, and favorite recipes\. The style should be warm and whimsical\."
> You can also upload a document with your detailed requirements for more convenience\.
> 
> 

Once you send your request, Codex will work in the background\. Here’s the initial result:

The basic structure and blocks are laid out, but it might lack some ideal elements\. That’s normal—Codex has just created the skeleton\.

### Step 2: Refine Details

Keep submitting modification requests to Codex to polish the details\. For example, if you want to adjust the layout of a section, you can:

1. Open the website preview in Codex\.

2. Click the plus sign in the top right corner\.

3. Select the area you want to modify and add a comment with your specific change, like:

> "Change the font color of the 'Cat’s Diary' section to a soft orange and increase the image spacing\."
> 
> 

### Step 3: Enhance with Images and Sections

If you want to add new sections \(e\.g\., a photo gallery, growth story, or favorite recipes\), describe them to Codex:

> "Add a photo gallery section with images of the cat napping, eating, and playing\. The layout should be a grid with hover effects\."
> If you don’t have images, use Codex’s built\-in **Image 2** feature to generate them\. For example:
> 
> 

```Plain Text
@image2 [橘猫阿福] 橘猫在花园里奔跑，阳光明媚，油画风格
@image2 [橘猫阿福] 橘猫在咖啡馆里喝咖啡，温馨场景，插画风格
```

Codex will generate suitable images, making your website content richer, especially in storytelling\.

### Step 4: Add Visual Effects and Animations

To make your website more dynamic, describe your desired effects to Codex\. If you need inspiration, browse resources like **React Bits** for backgrounds, text animations, and border effects\. Customize an effect \(e\.g\., a glowing text animation\), copy the code, and paste it into Codex with instructions:

> "Apply this glowing text animation to the 'Cat’s Motto' section\. The color should be light purple\."
> Codex will implement the animation, making your website more engaging\. For example, the text animation can mimic a cat’s gentle movement, and the background texture can follow the mouse cursor\.
>

## Method 2: Quick Creative Building

If you want a faster setup, use pre\-existing design references:

1. Find headings and landing page designs online \(e\.g\., from design platforms\)\.

2. Copy the prompt of a design you like\.

3. Paste the prompt into Codex and combine it with your own content ideas:

> "Use this landing page layout for a cat website\. Replace the content with my cat’s details: name 'Mikan', age 3, breed 'American Shorthair Tabby'\."
> 
> 

## Deploying Your Website Online

Your website initially runs only on your local computer\. To make it accessible to others, deploy it to a cloud platform like **Vercel**, **Alibaba Cloud**, or **Tencent Cloud**\. Here’s how to use Vercel:

1. Install the Vercel plugin in Codex\.

2. Log in to your Vercel account to authorize\.

3. In the Codex chat, mention the Vercel plugin:

> "@Vercel 部署这个猫咪网站上线"
> Codex will deploy your site and provide a public URL, like `https://your-cat-website.vercel.app`, so anyone can access it anytime\.
