# GitHub Weekly Trending: AI Tools and Agents Dominate the Chart

This week on GitHub, AI tools and Agents are making a splash, with video and memory\-related tools seeing rapid growth\. Let's dive into the top projects that developers are buzzing about\.

## 1\. OpenMontage

Turn your AI coding assistant into a **video production studio**\. Just describe your needs in one sentence, and it automatically handles the entire process from planning to rendering\.

- **Growth**: \+18\.0k stars in a week, totaling 25\.6k stars\.

- **Features**:

    - 12 production pipelines for animation, documentary, short film, and subtitle creation\.

    - 52 tools covering video generation, image creation, TTS, music, and subtitle processing\.

    - 500\+ Agent skills with expert guidance at each stage\.

    - Supports real material editing, making it more than just an image and animation generator\. It’s arguably the most complete open\-source video generation system out there\.

## 2\. Agent\-Reach

Empower your AI Agent to browse the web without needing API keys for platforms like Twitter, CSDN, Xiaohongshu, Reddit, and GitHub\.

- **Growth**: \+7\.7k stars in a week, totaling 4\.37k stars\.

- **Features**:

    - Supports 10\+ platforms\.

    - One\-click installation: Copy a line to your Agent, and it automatically configures everything\.

    - Automatic failover: If a platform is blocked, it switches to a backup solution without any user intervention\.

    - Just give a command to your Agent, and it handles configuration and calling on its own—no hassle for you\.

## 3\. codebase\-memory\-mcp

A must\-have for coders, this is an intelligent code MCP server that indexes your codebase into a knowledge graph\.

- **Growth**: \+7\.7k stars in a week, totaling 18\.0k stars\.

- **Features**:

    - Millisecond\-level queries for 158 programming languages\.

    - 99% reduction in token consumption compared to traditional methods\.

    - Indexes the 2\.8 million\-line Linux kernel in 3 minutes, with query responses under 1 millisecond\.

    - Single\-file installation with zero dependencies, compatible with 11 mainstream coding assistants like Claude Code and Cursor\.

## 4\. daily\_stock\_analysis

An LLM\-driven multi\-market stock analysis system\.

- **Growth**: \+7\.1k stars in a week, totaling 50\.6k stars\.

- **Features**:

    - Supports A\-shares, Hong Kong stocks, US stocks, Japanese stocks, and Korean stocks\.

    - Aggregates market data, news, and technical indicators to automatically generate buy/sell decision dashboards\.

    - Sends updates to WeCom, Feishu, or Telegram\.

    - Runs on GitHub Actions for zero\-cost scheduling\.

## 5\. Cognee

A long\-term memory platform for AI Agents\.

- **Growth**: \+5\.5k stars in a week, totaling 24\.1k stars\.

- **Features**:

    - Helps Agents remember important information across conversations\.

    - Supports data import, knowledge graph construction, and semantic search\.

    - End\-to\-end open\-source and self\-hostable, with PostgreSQL as the unified backend\.

    - Outperforms previous SOTA in BEAM benchmark tests, scoring 0\.79 in 100k token scenarios\.

## 6\. Anthropic\-Cybersecurity\-Skills

Equips AI Agents with 817 cybersecurity skills\.

- **Growth**: \+5\.1k stars in a week, totaling 22\.3k stars\.

- **Features**:

    - Maps to frameworks like MITRE ATT\&CK, NIST CSF, ATLAS, and more\.

    - Covers 29 security domains including cloud security, threat hunting, and incident analysis\.

    - Provides security expert\-level operation manuals for penetration testing, threat hunting, and DFIR\.

## 7\. ai\-website\-cloner\-template

A tool to clone websites with one command\.

- **Growth**: \+4\.6k stars in a week, totaling 22\.3k stars\.

- **Features**:

    - One command to clone a website: `ai-website-cloner <target-url>`\.

    - AI automatically analyzes the target site, extracts design specifications, builds each section in parallel, and merges them into clean Next\.js code\.

    - Uses TypeScript, Next\.js 16, and Tailwind CSS v4, with up\-to\-date technology\.

## 8\. Voicebox

An open\-source AI voice studio\.

- **Growth**: \+4\.0k stars in a week, totaling 35\.0k stars\.

- **Features**:

    - 7 TTS engines supporting 23 languages\.

    - Zero\-shot voice cloning and full transcription capabilities\.

    - Built with Tauri \+ Rust, enabling local execution for privacy and security\.

    - Supports switching pitch, reverb, and delay effects, compatible with engines like Queen3 TTS and Chatbox\.

## 9\. Penpot

An open\-source design tool competing with Figma\.

- **Growth**: \+3\.3k stars in a week, totaling 54\.2k stars\.

- **Features**:

    - Supports SVG, CSS, and HTML design, with real\-time collaborative design\.

    - Integrates with MCP servers for design\-to\-code workflow\.

    - Runs directly in the browser or can be self\-hosted, written in Clojure\.

    - Allows seamless handover of design drafts and direct export of usable code\.

## 10\. deer\-flow

A super Agent framework open\-sourced by ByteDance\.

- **Growth**: \+3\.3k stars in a week, totaling 75\.1k stars \(the highest on the list\)\.

- **Features**:

    - Driven by LAN graph, supporting sub\-Agent sandbox execution\.

    - Integrates IM channels like Telegram, Feishu, and WeChat\.

    - Breaks down complex tasks for sub\-Agents to execute in parallel, automating tasks from minutes to hours\.
